# Smart-Desk-Buddy
Smart Desk Buddy using Esp32-C3  (Emotions, Weather & Time Display )

`(Demo_image.pdf)`

A smart IoT-based desk companion that displays **Time, Weather, and Emotions** using an OLED display.

---

## 📌 About the Project

Smart Desk Buddy is a compact embedded system project built using **ESP32-C3**. It enhances your workspace by providing real-time information and interactive visual feedback.

---

## ✨ Features

* 🕒 Real-time Time Display
* 🌦️ Weather Updates (via WiFi)
* 😊 Animated Emotion Faces
* 🔊 Buzzer Feedback
* 👆 Touch Sensor Interaction

---

## 🛠️ Components Used

* ESP32-C3
* OLED Display (I2C)
* Buzzer
* Touch Sensor
* Breadboard / PCB
* Connecting Wires

## ⚙️ Setup Instructions

1. Install Arduino IDE
2. Install ESP32 Board Package
3. Install required libraries:

   * WiFi.h
   * Adafruit GFX
   * Adafruit SSD1306
4. Upload the code to ESP32
5. Connect components as per circuit diagram
